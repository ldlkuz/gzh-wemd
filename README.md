## 这个仓库重点改了什么

下面这些内容，属于当前仓库相对上游更强调、或已经做过定制调整的部分。

### 1. AI 接入策略重做

围绕“国内优先、免费优先、方便接入、自定义兜底”的方向，对 AI 接入做了重新整理：

- 优先内置国内主流模型服务商
- 保留免费 / 本地模型入口
- 保留自定义 OpenAI 兼容接口
- 对不同服务商做分组展示
- 按服务商能力控制“同步最新模型 / 同步本地模型”
- 改善模型拉取和鉴权报错提示

### 2. 公众号发布链路重新划分

把两个容易混淆的操作重新拉开：

- `复制到公众号`：复制富文本，适合直接粘贴到公众号正文编辑器
- `复制 HTML`：复制给插件使用的公众号最终 HTML 源码

这两个动作现在共享同一份发布 HTML 产物，减少“预览正常、插件不认、粘贴效果不一致”的问题。

### 3. 新增浏览器插件协作工作流

仓库内置了 `wechat-plugin` 浏览器插件，用来把 WeMD 生成的 HTML 源码插入到公众号后台。

这一部分主要增强了：

- 插件与 WeMD 的 HTML 产物对齐
- 插件插入正文时尽量保留排版
- 自动同步公众号顶部标题和作者
- 插件默认空白打开，不再保留上次缓存
- 桌面版自带 `wechat-plugin` 目录
- 程序内可直接打开插件目录和安装说明

### 4. 标题 / 作者元信息工作流

在编辑器中增加了更明确的公众号元数据维护能力：

- 可单独填写标题和作者
- 可通过复选框控制是否启用
- 标题可从正文 H1 一键同步
- 标题长度受限制保护
- 复选框状态会记忆
- 作者支持最近输入历史联想

当使用 `复制 HTML` 时，这些元信息会和 HTML 一起传给插件，插件再优先同步到公众号顶部输入区。

### 5. 文档与分发体验补齐

除了代码功能本身，这个仓库也把实际使用链路补得更完整：

- 插件有单独使用说明
- 主程序里增加插件目录和说明入口
- README 直接说明“上游是谁、这个仓库改了什么、该怎么用”

## 推荐使用方式

### 方式一：直接粘贴正文

适合只想尽快把正文贴到公众号的人：

1. 在 WeMD 中完成排版
2. 点击 `复制到公众号`
3. 到公众号正文编辑器中直接粘贴

### 方式二：通过插件插入源码

适合希望插件一起处理标题、作者和正文的人：

1. 在 WeMD 中完成排版
2. 按需填写并启用标题、作者
3. 点击 `复制 HTML`
4. 在公众号编辑页打开 `wechat-plugin`
5. 粘贴 HTML 源码并点击插入

## 插件工作流

`wechat-plugin` 是当前仓库的重要补充能力。

它主要负责：

- 接收 WeMD 复制出来的公众号 HTML 源码
- 解析显式传递的标题 / 作者元数据
- 把正文插入公众号编辑区
- 尽量同步顶部标题和作者输入框

详细安装和使用说明见：

- [wechat-plugin/使用说明.md](file:///e:/11自动工作流/wd/wechat-plugin/%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E.md)
