- **上游开源项目**：WeMD
- **上游作者 / 仓库**：`tenngoxars/WeMD`

## AI 辅助排版系统

这是当前版本最核心的增强。围绕"让 AI 真正帮你排版"，做了一整套从内容到样式的 AI 辅助能力。

### AI 能力总览

| 能力               | 说明                                     | 入口                            |
| ------------------ | ---------------------------------------- | ------------------------------- |
| 文本转 Markdown    | 把纯文本自动转换成结构化的 Markdown      | 工具栏「AI」按钮                |
| AI 设计 - 组件插入 | 分析文章结构，建议在合适位置插入排版组件 | 工具栏「AI 设计」→ 组件插入模式 |
| AI 设计 - 杂志排版 | 基于预设模板，生成杂志级完整排版         | 工具栏「AI 设计」→ 模板排版模式 |
| AI 主题生成        | 根据文章风格自动生成专属主题             | 主题面板「AI 生成」按钮         |

### AI 文本转 Markdown

**做什么的**：把一段没有格式的纯文本，自动转换成带标题、列表、引用、代码块等结构的 Markdown。

**使用场景**：

- 从其他地方复制来的纯文本，想快速排版
- 语音转文字后的原始文本
- 只有草稿，懒得手动加 Markdown 标记

**工作方式**：

1. 选中一段文本（或留空表示处理整篇）
2. 点击工具栏「AI」按钮
3. AI 分析文本结构，输出结构化的 Markdown
4. 转换温度设为 0.3，保证输出稳定可预期

### AI 设计：组件插入模式

**做什么的**：分析你的文章，告诉你"这里插一个 CTA 卡片会更好"、"这里适合加个引用块"，并自动插入对应的 V2 组件。

**使用场景**：

- 文章太干，不知道在哪里加视觉元素
- 想让排版更丰富，但不知道用什么组件
- 新手快速学习排版思路

**工作方式**：

1. 点击工具栏「AI 设计」，选择「组件插入」
2. AI 分析全文，生成文章画像（类型、受众、语气等）
3. AI 给出若干条插入建议，每条包含：组件类型、插入位置、插入理由
4. 你可以逐条预览效果，选择采纳或跳过
5. 也可以一键采纳全部建议

**技术细节**：

- AI 会感知当前主题的 layout 偏好（喜欢什么组件、密度如何、什么色调）
- 插入的组件使用 `::: component-type{props} ... :::` 语法
- 每条建议都可以单独预览，不影响原文

### AI 设计：模板排版模式

**做什么的**：基于预设的排版模板，把你的整篇文章重新编排成杂志级排版。

**使用场景**：

- 想快速得到专业排版效果
- 不知道怎么组织文章结构
- 需要统一风格的系列文章

**工作方式**：

1. 点击工具栏「AI 设计」，选择「模板排版」
2. AI 根据文章内容匹配合适的模板
3. 生成排版后的完整 Markdown
4. 可以预览效果，满意后应用

### AI 主题生成

**做什么的**：输入描述（比如"清新自然风格"、"科技感蓝色调"），AI 自动生成一整套公众号主题。

**使用场景**：

- 想要独特的排版风格，但不会写 CSS
- 想让每篇文章都有不同的视觉主题
- 快速试错，找到最合适的配色方案

**工作方式**：

1. 打开主题面板，点击「AI 生成」
2. 输入主题描述（或选择风格预设）
3. AI 生成主题定义 JSON，包含：
   - 颜色系统（主色、辅助色、背景色、文字色等）
   - 排版系统（字体、行高、间距等）
   - 组件样式（标题、引用、代码块、表格等）
4. 实时预览效果，满意后保存使用

**技术细节**：

- 生成的主题是结构化的 JSON，不是纯 CSS 字符串
- 支持主题设计器微调，可以在此基础上继续手动调整
- 生成温度设为 0.7，兼顾创意和稳定性
- 生成的 CSS 会经过安全过滤，过滤危险标签和属性

### AI 接入配置

所有 AI 能力都通过前端直连 AI 服务商，无需后端：

- **兼容 OpenAI 格式**：所有请求都走 OpenAI 兼容的 API 格式
- **多服务商支持**：支持国内主流服务商、OpenRouter、自定义 Base URL
- **动态模型拉取**：通过 `GET {baseUrl}/models` 自动获取可用模型
- **本地缓存**：模型列表缓存在 localStorage，离线也能用
- **一键刷新**：手动刷新模型列表，显示最后更新时间
- **失败静默**：网络请求失败时自动降级使用缓存，不打断使用

## V2 组件系统

在基础 Markdown 之外，新增了一套组件化排版语法，让公众号排版更丰富。

### 组件语法

```markdown
::: cta-card{title="立即关注" buttonText="去关注" url="https://..."}
点击关注，第一时间获取最新内容
:::
```

渲染后会变成带样式的 `<section>` 标签，由主题控制具体外观。

### 组件分类

- **基础组件**：CTA 卡片、引用卡片、代码框、图片网格、作者卡片、时间线、数据统计等
- **杂志组件**：杂志封面、双栏卡片、图片卡片、文字卡片、全幅引用、结束卡片等
- **扩展组件**：关注引导、英雄横幅、二维码卡片、相关文章、章节标题、目录导航、版权声明等
- **FAQ 组件**：问答列表

## 主题系统

### 内置主题

内置 30+ 套主题，涵盖多种风格：

- **基础类**：basic、modern-editorial（现代编辑风）、components-default 等
- **商务类**：bauhaus（包豪斯）、data-blueprint（数据蓝图）
- **学术类**：academic-paper（学术论文）、knowledge-base（知识库）
- **创意类**：cyberpunk-neon（赛博朋克）、neo-brutalism（新野兽派）
- **自然类**：morandi-forest（莫兰迪森林）、eastern-notes（东方笔记）
- **极简单**：whitespace-gallery（留白画廊）、receipt（收据风）
- **科技类**：aurora-glass（极光玻璃）、luxury-gold（奢华金）
- **代码类**：code-github、code-github-dark

### 主题架构

- **设计令牌（Design Token）**：颜色、字体、间距等基础变量统一管理
- **组件样式独立**：每个组件的样式拆分为独立文件，主题文件不臃肿
- **变体系统**：同一组件支持多种风格变体，通过 `data-variant` 切换
- **深浅双模式**：所有主题都支持深色模式
- **响应式**：移动端自动适配

## 公众号发布链路

### 两种复制方式

- **复制到公众号**：复制富文本，直接粘贴到公众号正文编辑器
- **复制 HTML**：复制 HTML 源码，配合浏览器插件使用

两种方式共享同一份发布产物，保证预览和实际效果一致。

### 浏览器插件联动

内置 `wechat-plugin` 浏览器插件，用于把 HTML 源码插入公众号后台：

- 自动同步标题和作者到公众号顶部输入框
- 正文样式保留更完整
- 桌面版自带插件目录，菜单里可直接打开

### 元信息管理

编辑器内直接管理公众号元信息：

- 标题：可从正文 H1 一键同步，带字数限制保护
- 作者：支持最近输入历史联想
- 复选框控制是否启用，状态自动记忆

## 推荐使用方式

### 方式一：直接粘贴正文

适合只想尽快把正文贴到公众号的人：

1. 在 WeMD 中完成排版
2. 点击「复制到公众号」
3. 到公众号正文编辑器中直接粘贴

### 方式二：通过插件插入源码

适合希望插件一起处理标题、作者和正文的人：

1. 在 WeMD 中完成排版
2. 按需填写并启用标题、作者
3. 点击「复制 HTML」
4. 在公众号编辑页打开 `wechat-plugin`
5. 粘贴 HTML 源码并点击插入

### 方式三：AI 辅助创作

适合希望 AI 帮助排版和生成主题的人：

1. 输入或粘贴文章内容
2. 用「AI 转换」把文本转成结构化 Markdown
3. 用「AI 设计」选择组件插入或模板排版
4. 用「AI 主题」生成专属排版风格
5. 预览满意后发布

## 本地开发

### 环境要求

- Node.js >= 18
- pnpm >= 9

### 快速开始

```bash
# 安装依赖
pnpm install

# 启动 Web 开发服务器
pnpm dev:web

# 启动桌面端（Electron）
pnpm dev:desktop
```

### 构建命令

```bash
# 构建 Web 端
pnpm --filter @wemd/web build

# 构建桌面端（Windows）
pnpm --filter wemd-electron build:win

# 构建桌面端（macOS）
pnpm --filter wemd-electron build:mac

# 构建桌面端（Linux）
pnpm --filter wemd-electron build:linux
```

### 其他命令

```bash
# 代码检查
pnpm lint

# 代码格式化
pnpm format

# 运行测试
pnpm --filter @wemd/web test
```
