# 数据蓝图 · AI 排版组件手册

> 风格：科技蓝 / 理性专业。
>
> 这是一套"把信息当数据排给人看"的版式——科技蓝主调、理性、专业，适合技术文章、数据报告、行业分析类内容。体面不在花哨，而在把复杂讲清楚：一段结论一屏、一组数字整齐、代码干净、表格对齐。拿一份真报告，它应当是克制的、可信的、有据可查的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配——普通标题、表格、代码、引用、图片，直接写即可，无需专用语法。下面的组件（含主题推荐优先用的）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

## 数值 / 表格（本主题核心）

**数据指标块（推荐优先用 · 一组核心数字）**

::: stats-block
{标题，如 年度核心数据}

- {数值，如 +38%}
  说明，如 同比增速
- {数值，如 1200w}
  说明，如 活跃用户
  :::

**数据表格（推荐优先用 · 原生表格自动适配，列对齐）**

| 指标 | 2025 | 2026 |
| ---- | ---- | ---- |
| 营收 | 800  | 1100 |
| 增速 | 12%  | 38%  |

> 表格直接写 markdown `| 列 | 列 |` 即可，系统自动适配为均匀列宽的数据表。

**代码块（推荐优先用 · 原生代码围栏自动适配）**

```js
const growth = (2026 - 2025) / 2025;
console.log(`增长率 ${growth * 100}%`);
```

> 代码直接写 ```围栏即可，系统自动适配为代码框，无需`:::`。
