# 默认主题 · AI 排版组件手册

> 风格：通用 / 清新编辑式。
>
> 这是一套"不抢戏"的底子——干净的纸面、有一点微信绿的呼吸、几处克制的点缀。它适合几乎所有内容：生活、资讯、随笔、清单都能稳稳立住。体面不在装饰堆砌，而在版面的秩序：标题把节奏管好、正文透气、要点被适度标出，读起来不累也不乱。组件是用来"标注最重要的东西"的，不是用来铺满页面的。真正的好稿子，翻起来是清爽的、可信的、恰到好处的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配。需要 `::: 组件id` 包裹的才是下面的特殊组件。

---

---

其余原生组件（普通标题、引用、表格、代码块、分隔线、单图、多图）直接写 markdown 即可自动适配，无需 `:::`。只有内容真的需要上面这种专用结构时，才去用对应的 `:::` 组件，照抄示例、每类最多一个。
