# 落日胶片 · AI 排版组件手册

> 风格：胶片黄昏 / 怀旧摄影。
>
> 这是一套"黄昏胶片"的版式——落日橙、暮紫、颗粒与漏光，像洗出来的一卷旧底片。它适合旅行、摄影、故事、回忆类内容。体面不在sharp，而在情绪：画面是旧的、时间是慢的、每一帧都值得停下来看。拿一卷真胶片，它应当是暧昧的、有温度的、带着颗粒质感的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
