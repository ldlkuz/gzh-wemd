# 民宿纪 · AI 排版组件手册

> 风格：原木奶盏 / 慢住民宿。
>
> 这是一套"把一间好居所摆给人住"的版式——燕麦米白承载、暖木陶土、鼠尾草绿点缀，像一份有温度的手写住店手记。它适合民宿推介、住一晚手记、度假清单类内容。体面不在奢华，而在留得住人：一间民宿一张暖光大图、木牌编号清清楚楚、价格诚诚恳恳、一句推荐点到心里。拿一间真居所，它应当是有呼吸的、有角落在发光的、让人想放慢下来住一晚的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
