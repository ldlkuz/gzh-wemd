# 知识库 · AI 排版组件手册

> 风格：知识档案库 / 理性档案。
>
> 这是一套"把知识整理成档案"的版式——墨蓝打底、米纸写字、索书号气息，像存进档案馆的一份好资料。它适合知识管理、文档系统、读书笔记、整理好的知识库内容。体面不在花哨，而在条理：条目归进抽屉、章节有编号、重点被卡片收住，找得到、读得进。拿一份真档案，它应当是专业的、干净的、经得起随时翻查的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
