# 黑金奢华 · AI 排版组件手册

> 风格：黑金 / 高端奢华。
>
> 这是一套"高定"的版式——暖米纸底、深棕字、金色贯穿装饰，像一份矜贵的品牌手册或高定服务页。它适合品牌营销、高端内容、轻奢产品、品质生活类内容。体面不在堆料，而在分寸感：金用得克制、留白给足、一份内容只撑起一件主角。拿一件真正的致品，它应当是典雅的、热烈的、让人愿意多看两眼的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
