# 小票 · AI 排版组件手册

> 风格：购物小票 / 热敏纸。
>
> 这是一套"把内容打在一张热敏小票上"的版式——店名票头、单号分行、虚线分隔、会员集章，像刚从收银机递出的一张新鲜小票。它适合清单、账单、轻量攻略、条理性内容。体面不在豪华，而在爽脆利落：一行一行的信息、一条一条的分隔、干净得像真发票。拿一份真清单，它应当是有趣的、清楚的、让人想一行行读完的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---
