# 好物种草 · AI 排版组件手册

> 风格：温暖日杂 / 买手种草。
>
> 这是一套"把好东西摆给人看"的版式——实物摄影、编号标签、珊瑚橘价格签，像一本温暖的手作买手清单。它适合好物推荐、开箱、种草清单类内容。体面不在堆货，而在让人心动又可信：一件好物一张图、编号清清楚楚、价格诚诚恳恳、理由说到点子上。拿一件真种草，它应当是有主张的、有温度的、让人看完想下单的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
