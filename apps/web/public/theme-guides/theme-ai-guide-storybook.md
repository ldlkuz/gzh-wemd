# 故事集 · AI 排版组件手册

> 风格：暖纸故事 / 沉浸阅读。
>
> 这是一套"把故事摆上桌"的版式——纯图封面、暖纸衬线、章节慢速展开，像翻开一本想一直读下去的故事书。它适合短篇故事、个人叙事、旅行随笔类内容。体面不在炫技，而在让人读得进：封面引一句、章节轻轻切开、金句在情绪该停的地方顿一下。拿一篇真故事，它应当是温暖的、有呼吸的、让人忘了时间流逝的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---

## 封面 / 收束

**纯图封面（专属 · 图 + 标题 + 引子句叠层 · 全篇最多一个）**

::: magazine-cover
{主标题，如 山那边有一棵树}
{副题一句，如 一个关于眺望的故事}
{引子句，如 那年的秋天，她想再看看那棵树。}
![封面图](https://via.placeholder.com/1200x630)
:::

**首屏横幅（如需要文字开篇）**

::: hero-banner
![背景图](https://via.placeholder.com/1200x630)
{主标题，如 序}
{副标题一句话}
:::

**结尾（专属 · 「完」+ 后记 · 全篇最多一个）**

::: end-card
{结尾语，如 完}
{后记一段，可多段，写故事的余味}
:::

:::

## 引用 / 提示（情绪停顿点）

**金句卡（专属 · 居中双线 + 引号）**

::: quote-card
{金句一句，如 她终于明白，等待也是一种出发}
**{出处，如 故事 · 第七章}**
:::

**整段引用（原生引用居中）**

::: full-quote
{引用文字，可多行}
:::

**对话 / 旁白卡（专属 · 纸面块）**

::: callout
**{提示标题}**

:::

**提示条**

::: callout-pro

:::

---

**其余原生组件（普通标题、引用、表格、代码块、分隔线、单图、多图）直接写 markdown 即可自动适配，无需 `:::`。只有内容真的需要上面这种专用结构时，才去用对应的 `:::` 组件，照抄示例、每类最多一个。**
