# 清晰指南 · AI 排版组件手册

> 风格：学习手册 / 上手向。
>
> 这是一套"被认真学过一遍的手册"的味道——暖纸为底、荧光划重点、橙红落笔签名，像是在纸边做过的笔记。它适合教程、上手文档、学习方法、操作指南类内容。体面不在花哨，而在好读：重点被荧光标出、步骤清清楚楚、提醒落在眼睛能看见的地方。拿一本真手册，它应当是清晰的、亲和的、让人能一步步照做的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
