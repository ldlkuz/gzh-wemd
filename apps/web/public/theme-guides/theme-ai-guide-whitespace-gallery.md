# 留白画册 · AI 排版组件手册

> 风格：极简 / 留白 / 设计感。
>
> 这是一套"把页面留出很多空气"的版式——黑白为主，大量留白，字少而精，强调而不是铺陈。它适合品牌展示、设计作品、理念陈述、极简主义内容。体面不在内容多少，而在取舍的干净：一个版面只突出一个重点，其余交给留白与节奏。拿一件真正的作品，它应当是简约的、优雅的、经得起细看的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---

## 封面 / 收束

{导语一句，如 把一件作品，讲清楚。}
:::

**首屏横幅（如需要大字开篇）**

---

其余原生组件（普通标题、引用、表格、代码块、分隔线、单图、多图）直接写 markdown 即可自动适配，无需 `:::`。只有内容真的需要上面这种专用结构时，才去用对应的 `:::` 组件，照抄示例、每类最多一个。
