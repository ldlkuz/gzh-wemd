# 无声发布 · AI 排版组件手册

> 风格：发布会 / 极简舞台。
>
> 这是一套"无声发布会"的版式——黑屏开场、白场正文、黑屏收场，一抹荧光橙舞台光。它适合科技、产品发布、年度回顾类内容。体面不在热闹，而在留白：一句话一件重点、一屏一个层级，像站在舞台中央只讲一件大事。拿一场真发布会，它应当是干净的、克制的、有仪式感的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---
