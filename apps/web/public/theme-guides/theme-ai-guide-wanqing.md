# 晚晴 · AI 排版组件手册

> 风格：写给岁月的一份温柔。
>
> 这是一套"写给长辈、也写给往事的版式"——米纸承载、楷宋书卷气、赭橘唯一强调色、墨绿叶脉轻轻点缀。它适合老年情感、怀旧随笔、家常家书与岁月感悟类内容。体面不在热闹，而在可读、可信、可慢读：大字、高对比、宽行距，少装饰干扰，像一封摊在旧桌上的家书。拿一份真岁月，它应当是暖的、静的、字字都能看清的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---
