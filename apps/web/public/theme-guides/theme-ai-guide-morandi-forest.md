# 莫兰迪森林 · AI 排版组件手册

> 风格：雾林 / 层林 · 柔和自然。
>
> 这是一套"把生活写进一片雾林"的版式——莫兰迪的柔和色、自然的呼吸感，适合生活方式 / 情感类内容。体面不在炫酷，而在干净与温柔：林冠叶片轻轻垂下、章节号大方沉静、金句像果实一样挂下来、结尾收在深松的安静里。拿生活里一段真话，它应当是柔的、静的、有草木气息的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---
