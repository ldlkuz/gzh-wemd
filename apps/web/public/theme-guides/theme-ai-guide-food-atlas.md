# 美食图谱 · AI 排版组件手册

> 风格：现代美食 / 探店图谱。
>
> 这是一套"把好吃的按图谱排给人看"的版式——暖橙主调、圆角卡片、TOP 排名徽章、干净标签，像一份有榜单感的美食探店图谱。它适合美食探店、菜品图谱、好味清单类内容。体面不在堆料，而在让人垂涎又可信：一道菜一张全幅图、排名清清楚楚、门店与口味写到点子上。拿一份真图谱，它应当是有食欲的、有条理的、让人想立刻去吃的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配，无需任何专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。
