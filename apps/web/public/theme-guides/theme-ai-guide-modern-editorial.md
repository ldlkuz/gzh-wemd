# 现代编辑部 · AI 排版组件手册

> 风格：编辑部 / 纸媒调性。
>
> 这是一套"铅字时代"的版式——大刊头、编辑号、栏线、超大引号，像一份摊开在编辑桌上的正经报纸。它适合报道、深度长文、专栏、评论类内容。体面不在装饰，而在信息层级的干净：大标题撑住、段落透气、金句只在一处放大，其余靠留白和节奏。拿一份真稿子，它应当是克制的、可信的、一丝不苟的。
>
> 原生 markdown 按你所熟悉的方式自由书写即可，系统会全部自动适配——普通标题、引用、表格、代码、图片，直接写即可，无需专用语法。下面的组件（含本主题专属组件）都必须用 `::: 组件id` 包裹，照抄示例，每类最多一个。

---
