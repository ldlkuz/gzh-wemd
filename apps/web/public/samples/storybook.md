::: text-card
第一段 · 引子

雾从海上漫上来的时候，灯塔刚刚亮起。老周在这座灯塔守了三十一年。他总说，雾天最见人心——夜航的人会一盏一盏地点亮自己的灯，可总有一两盏，会在雾里多停一会儿，像在等一句没说完的话。
:::

::: section-divider
壹
灯芯
:::

第一年守塔，老周总在灯下写信。写给谁？他没说，只说是写给一个"在雾里走丢了的人"。他写得极慢，一个字一个字地落笔，像在给每一句话，找一条归航的路。写完，他把信放进铁皮匣里，谁也不许看。

第二十一年，一场大雾困住了整片海。雾里有船笛，断断续续，像某种呼救。老周那晚没有睡，把灯擦得锃亮，又添了半寸灯芯。海面忽然安静下来的时候，天已经快要亮了。

::: quote-card
「雾可以遮住方向，却遮不住一盏灯的去意。」

**—— 老周**
:::

三十一年，一千一百多封信。铁皮匣从一只，变成了一整面墙。
:::

::: section-divider

来信

后来，我替镇上的孩子给老周捎过一封信。信上没有署名，只写着："夜航的人回来了。谢谢你的灯。"

老周看了很久，忽然笑了。他说，这下，可以换一根新灯芯了。

::: callout
**孩子**
「这封信，是写给谁的？」

**老周**
「写给所有在雾里赶路的人。」
:::

::: end-card

后记

第二年春天，灯塔换了新人。老周把那面铁皮墙留了下来，只带走一盏旧灯。雾散的时候，有人看见他在镇口站了很久，像是在等一艘早已靠岸的船。
