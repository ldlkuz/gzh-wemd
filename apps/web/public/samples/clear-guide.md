## 01 准备工作

在开始之前，请先确认你已准备好以下两样东西：一个微信公众平台账号，以及一份想排版的内容草稿。

> 重要：请使用最新版 Chrome 或 Edge 浏览器，避免兼容性问题。

## 02 三步走

::: steps
新手三连击

1. **新建文章** — 打开编辑器，粘贴你的 Markdown 草稿
2. **选择主题** — 在右侧面板挑选一套喜欢的主题样式
3. **一键导出** — 点击导出，复制 HTML 粘贴到公众号即可
:::

## 03 常见问题

::: faq{title="新手指南"}
**导入模板后没有生效？**

确认主题已「应用」而不是仅「预览」，应用后编辑器会即时刷新样式。

**图片显示不出来？**

请使用编辑器自带的图片上传功能，外部图片链接会被微信防盗链拦截。

**如何调整主题色？**

在主题设计中，点击「视觉编辑」修改主色变量，保存后全站即时生效。
:::

## 04 技巧与检查清单

::: callout

- 所有图片已上传至图床，无外链
- 标题层级规范，无跳级
- 在手机预览模式下检查一遍排版
