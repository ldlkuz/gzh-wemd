# WeMD 公众号插件使用说明

这个插件用于配合 **WeMD** 使用，把 WeMD 生成的公众号 HTML 源码插入到微信公众号编辑器中，并尽量自动同步顶部的标题和作者。

---

## 适用场景

- 你在 **WeMD** 里用 Markdown 写内容
- 你希望保留 WeMD 生成的公众号排版效果
- 你需要把内容插入到公众号后台，并自动处理标题、作者、正文

---

## 第一步：安装插件

### Chrome

1. 打开 `chrome://extensions/`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择当前 `wechat-plugin` 文件夹

### Edge

1. 打开 `edge://extensions/`
2. 开启 **开发人员模式**
3. 点击 **加载解压缩的扩展**
4. 选择当前 `wechat-plugin` 文件夹

安装完成后，进入公众号图文编辑页，页面右侧会出现插件悬浮按钮。

---

## 第二步：在 WeMD 中准备内容

1. 在 WeMD 中编写 Markdown
2. 如需同步公众号顶部信息，可在编辑器上方填写：
   - `标题`
   - `作者`
3. 对应复选框勾选后，复制的 HTML 才会明确携带这些信息
4. 点击 **复制 HTML**

这里的 **复制 HTML**，复制的是给插件使用的 **公众号最终 HTML 源码**，不是普通网页片段。

---

## 第三步：插入到公众号后台

1. 用已安装插件的浏览器打开微信公众号后台
2. 进入 **新建图文 / 编辑文章** 页面
3. 点击右侧插件悬浮按钮，打开面板
4. 将刚刚从 WeMD 复制的 HTML 源码粘贴到插件输入框
5. 点击 **插入**

插件会尝试完成这些动作：

- 把 HTML 正文插入公众号正文编辑区
- 优先使用 WeMD 显式传来的标题
- 优先使用 WeMD 显式传来的作者
- 当未提供标题或作者时，再回退到正文内容里做有限推断

---

## 当前行为说明

- 插件打开时默认是空白状态，不会自动带出上次内容
- 标题和作者会优先读取 WeMD 复制结果中的显式元数据
- 如果你没有勾选使用标题或使用作者，插件就不会强制填这两个字段
- 插件会尽量保留 WeMD 输出的公众号排版结构，但最终显示仍受公众号后台过滤规则影响

---

## 推荐工作流

### 方式一：需要插件自动填标题/作者

1. 在 WeMD 中填写并勾选标题、作者
2. 点击 **复制 HTML**
3. 粘贴到插件
4. 点击 **插入**

适合需要同步公众号顶部标题、作者的场景。

### 方式二：只需要把排版内容贴到公众号

1. 在 WeMD 中直接点击 **复制到公众号**
2. 到公众号正文编辑器中手动粘贴

这种方式走的是富文本复制链路，更适合快速贴正文，但不会通过插件面板处理源码。

---

## 常见问题

**Q：插件按钮没有出现？**  
A：先确认当前页面是公众号图文编辑页，然后刷新页面，等待几秒让插件初始化。

**Q：为什么我粘贴 HTML 后没有同步标题或作者？**  
A：请先确认你是在 WeMD 中点击的 **复制 HTML**，并且对应的标题/作者复选框处于勾选状态。

**Q：为什么插件打开后是空的？**  
A：这是当前设计。插件不会再缓存上一次输入内容，需要你每次手动粘贴新的 HTML。

**Q：样式和 WeMD 预览有少量差异正常吗？**  
A：正常。公众号后台会过滤部分样式，插件已经尽量按公众号兼容方式插入。

- 查看插件安装说明
