# 字节跳动 · 公众号主题测试表单材料包

## 项目类型

🏢 **品牌项目** (Brand Profile)

---

## 一、必填字段（直接复制到表单对应输入框）

| #   | 表单字段 ID                                      | 填写内容                              |
| --- | ------------------------------------------------ | ------------------------------------- |
| 1   | `pf-name` (品牌名称)                             | 字节跳动                              |
| 2   | `pf-description` (品牌介绍，100-300字)           | 见下 "品牌介绍原文"                   |
| 3   | `pf-keywords` (品牌关键词，3-5个，逗号/空格分隔) | 科技, 全球化, 创新, 多元, 年轻        |
| 4   | `pf-logo` (品牌 Logo，上传文件)                  | 选择本文件夹中的 `bytedance-logo.png` |

```

```

## 三、字段速查（前端实际 DOM ID 对照）

```
pf-name           →  品牌名称 *
pf-description    →  品牌介绍 *
pf-keywords       →  品牌关键词 *
pf-logo           →  Logo 上传 *
pf-primaryColor   →  品牌主色（选色器）
pf-slogan         →  Slogan
pf-website        →  官方网站 URL
pf-brandSpec      →  品牌规范 PDF（可选）
```

---

## 四、使用步骤

1. 在 Theme Studio 点击「新建项目」
2. 项目名称填入：**字节跳动**
3. 项目类型选择：🏢 **品牌项目**
4. 点击「创建项目」进入资料收集页
5. 按上表逐一粘贴/选择内容
6. 点击「保存并开始生成」
7. 系统状态变为 `READY`，等待 Skill 触发 AI 主题生成
