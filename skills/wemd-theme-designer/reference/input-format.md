# 输入格式

材料提供阶段只收集**装饰层**所需的最小素材集。内容层素材（产品图片、摄影作品等）不在此收集，由主程序走外链图库。

## 必填（5 项）

```text
品牌名称：<string>
品牌类型：<企业 | 个人创作者 | 媒体 | 产品 | 机构 | 社区>
行业：<所属行业，如 工业机器人>          ← 差异化信号之一
目标客户：<服务对象，如 汽车制造企业>     ← 差异化信号之一
品牌介绍：<100-300 字，决定语气与风格方向>
```

> **行业与目标客户设为必填**：它们是推导视觉母题（visual_metaphor）的关键差异化信号。仅靠品牌名称和介绍，AI 容易退化成"科技=蓝渐变"的行业套路；有了行业与客户，母题推导才有依据。

## 品牌档案（可选，强烈建议补充）

以下字段不是必填，但**填写越完整，母题越独特**。用户可用自然语言填写，AI 负责结构化提炼：

```text
品牌关键词：<3-5 个，决定装饰风格方向>
产品：<核心产品或服务，如 自动化生产线机器人>
希望别人怎么看你：<期望的用户认知，如 行业专家 / 创新先锋 / 长期伙伴>
避免方向：<不希望看起来像什么，如 互联网创业风 / 过度炫酷 / 赛博朋克>
```

> **`avoid`（避免方向）是最有力的反向信号**：它告诉 AI"不能像什么"，反向锁定母题。AI 默认会往流行方向靠，这个约束能有效矫正。

## 文件资产（1 项）

```text
Logo 图片   ← 唯一真正需要的素材文件
```

品牌颜色、Icon、品牌图形等不单独要文件——主色从 Logo 提取，图形优选 CSS 代码化表达。

## 可提取（不占素材文件）

```text
品牌主色   ← 从 Logo 提取
辅助色     ← 从 Logo / 文本提取
已有视觉资产 ← 从上传的 Logo / VI 手册 / 官网截图 / 宣传册 中分析（几何结构、直线曲线、色调、质感）
```

## 可选（文本，沿用）

```text
Slogan
品牌定位
品牌使命
品牌价值观
目标受众
内容类型
设计目标
品牌规范 PDF（仅用于提取规范）
```

## 不在此收集

```text
产品图片、摄影作品   → 内容层，走外链图库
字体               → 移除（公众号发布禁用外部字体，用系统字体栈）
```
