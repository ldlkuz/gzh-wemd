# 输入格式

**主入口是 `input.html` 表单**：用户打开表单按类型逐项填写，点击「生成 JSON」导出结构化输入，交给 Stage 1（品牌解读）直接消费。表单输出严格遵循 `schema/input.schema.json`，Stage 1 不依赖历史对话，只读这份 JSON。

> 自然语言输入仅作为兜底：用户直接描述品牌时，agent 按 `input.schema.json` 的字段结构把描述结构化，产出同一结构的 JSON。

材料提供阶段只收集**装饰层**所需的最小素材集。内容层素材（产品图片、摄影作品等）不在此收集，由主程序走外链图库。

## 必填（5 项）

```text
品牌名称：<string>
品牌类型：<企业 | 个人创作者 | 媒体 | 产品 | 机构 | 社区>
行业：<所属行业，如 工业机器人>          ← 差异化信号之一
目标客户：<服务对象，如 汽车制造企业>     ← 差异化信号之一
品牌介绍：<100-300 字，决定语气与风格方向>
```

> **行业与目标客户设为必填**：它们是推导视觉母题（visual_metaphor）的关键差异化信号。仅靠品牌名称和介绍，AI 容易退化成"科技=蓝渐变"的行业套路；有了行业与客户，母题推导才有依据。

> **创作者（`creator`）类型的差异化信号重映射**：创作者没有真正的行业/客户，必填的「行业」「目标客户」改填「创作主题 / 领域」与「受众 / 读者」（见表单）。母题推导的主导信号随之变为 `personality + 创作主题 + 内容气质 + 受众`，而非品牌模式的"行业 + 客户"。详见 `prompts/01-brand.md` 的创作者模式一节。

## 品牌档案（可选，强烈建议补充）

以下字段不是必填，但**填写越完整，母题越独特**。用户可用自然语言填写，AI 负责结构化提炼：

```text
品牌关键词：<3-5 个，决定装饰风格方向>
产品：<核心产品或服务，如 自动化生产线机器人>
希望别人怎么看你：<期望的用户认知，如 行业专家 / 创新先锋 / 长期伙伴>
避免方向：<不希望看起来像什么，如 互联网创业风 / 过度炫酷 / 赛博朋克>
```

> **`avoid`（避免方向）是最有力的反向信号**：它告诉 AI"不能像什么"，反向锁定母题。AI 默认会往流行方向靠，这个约束能有效矫正。

## 不收集图片素材

主题设计要的是**从图片抽象出的气质描述**（几何、线条、色调、质感），不是图片本身。`existing_assets` 由用户文字描述（如"Logo 是圆润曲线、暖色调、科技感"）或对话多模态 AI 提炼，**表单不收集图片文件**。

品牌主色从描述的色调倾向提取，图形优选 CSS 代码化表达。

## 可提取（不占素材文件）

```text
品牌主色   ← 从 Logo 提取
辅助色     ← 从 Logo / 文本提取
已有视觉资产 ← 从用户描述或对话附图中分析（几何结构、直线曲线、色调、质感）
```

## 可选（文本，沿用）

```text
Slogan
品牌定位
品牌使命
品牌价值观
目标受众
内容类型
设计目标
品牌规范 PDF（仅用于提取规范）
```

## 不在此收集

```text
产品图片、摄影作品   → 内容层，走外链图库
字体               → 移除（公众号发布禁用外部字体，用系统字体栈）
```
