# 预设风格关键词清单

> 无论企业还是创作者，都必须从以下关键词中选择 **3~5 个**。
> 选得越少，风格越聚焦；超过 5 个会互相冲突。
> 这套清单是两种 Profile 模板共用的。

---

## 输入校验（AI 必须执行）

在开始生成前，如果用户选择的关键词：

- **少于 3 个**：提示「请至少选择 3 个风格关键词」
- **多于 5 个**：提示「关键词超过 5 个会风格混乱，请去掉 1~2 个」
- **组合冲突**（如 极简 + 活力、温暖 + 稳重）：提示「以下关键词组合可能冲突，是否确认使用？」并列出冲突对
- **不在本清单内**：自动映射到最接近的 18 个预设词，或提示加入清单
