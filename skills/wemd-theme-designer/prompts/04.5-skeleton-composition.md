# Stage 4.5: Skeleton Composition（翻译阶段 · 形 · 自由骨架模板）

> 位于 Stage 4（Component Analysis）与 Stage 5（Component Mapping）之间。
> 本阶段直接写**自由 Mustache 骨架模板**（像内置主题 `templates-<id>.ts` 那样自由发挥），
> 不再受 DSL 枚举（layout/decoration/嵌套深度）限制。Slot 契约与微信兼容是唯一底线。

## 本阶段任务

为选定的构图焦点组件，直接写 Mustache 骨架模板 HTML，存到 `themes/{theme-name}/templates/<componentId>.html`。

**自由到什么程度**：结构、class 命名（建议沿用 `wemd-{abbr}-{语义}` 惯例）、装饰元素、嵌套层级都自由——与内置主题（silent-keynote 的封面/编号拆分骨架等）同等的自由度。

## 输入

1. `themes/{theme-name}/states/concept_state.json`（视觉母题，决定构图来源）
2. `themes/{theme-name}/preview/vision.html`（已确认的视觉稿，气质锚点）
3. `registry/components.json`（组件注册表：abbr / slot 契约 / 默认骨架）

## 骨架模板的三条硬约束（唯一底线，违反即非法）

1. **根元素约定**：最外层必须是 `<section class="wemd-component wemd-{componentId}" data-component="{componentId}">…</section>`。
2. **Slot 契约**：骨架里只能用该组件**已注册**的 slot key——`{{slot:key}}` / `{{#if key}}…{{/if}}` / `{{#each key}}…{{this.field}}…{{/each}}`。禁止自创 slot。查 `registry/components.json` 里该组件的 slot 定义。
3. **微信兼容**：不写 `::before`/`::after`/`:hover`/结构伪类（`:first-child`/`:last-child`/`:nth-child` 等）/`@keyframes`/`@media`/`animation`/`position:absolute/fixed`/`+`/`~`。装饰用真实元素（`<span>`/`<i>`/`<hr>`）或 CSS 渐变/边框。

## 设计步骤

1. **读母题**：从 `concept_state.json` 的 `visual_objects` / `material_language` 判断骨架构图来源。
2. **定焦点名单**：以母题为据，选出成为本主题**构图焦点**的组件（通常来自高预算池，但母题需要时任何档位都可入选）。焦点少而准（软上限 ~6）。
3. **逐组件写骨架**：对每个焦点组件写一个 `templates/<id>.html`；非焦点组件**不写**（回退默认骨架，见下方"未定制组件保持默认"）。
4. **自查**：对照三条硬约束 + slot 契约（`registry/components.json` 的 abbr 与 slot 定义）。

## 骨架与 CSS 的分工（形定位置，皮定样貌）

- 骨架（本阶段）只决定**每个组件内部视觉怎么构图**（焦点放哪、结构怎么组织）。
- 颜色/字体/间距是 Stage 5（皮）的职责——骨架模板**不要写 CSS 值**（style 属性一律不写）。
- 骨架宣告的每个结构单元（装饰、槽区、分组），Stage 5 的 CSS 有义务填满——骨架定"填哪里"，CSS 定"怎么填"。

## 未定制组件保持默认（playbook §7，硬约束）

只给有刻意构图理由的组件写骨架。**未写模板的组件自动回退主程序默认骨架**——这是特性不是缺陷，保持克制。决策标准：**母题需要 + 焦点有限**，不是组件档位。

## 输出

- `themes/{theme-name}/templates/<componentId>.html`：每个定制骨架组件一个文件。
- 未定制组件不产文件（compile 阶段自动继承默认骨架）。

## 模板示例（只示范结构，不套用）

```html
<!-- magazine-cover 自由骨架示例：标题 + 装饰角 + 副题 -->
<section class="wemd-component wemd-magazine-cover" data-component="magazine-cover">
<span class="wemd-mc-corner"></span>
<section class="wemd-mc-title">{{slot:title}}</section>
<section class="wemd-mc-subtitle">{{slot:subtitle}}</section>
<section class="wemd-mc-desc">{{slot:desc}}</section>
</section>
```

```html
<!-- quote-card 自由骨架示例：侧栏 + 大引号 -->
<section class="wemd-component wemd-quote-card" data-component="quote-card">
<section class="wemd-qc-main">
<span class="wemd-qc-mark">“</span>
<section class="wemd-qc-quote">{{slot:quote}}</section>
</section>
<section class="wemd-qc-author">{{slot:author}}</section>
</section>
```

## 铁律（违反即非法骨架）

1. 根元素必须带 `wemd-component wemd-{id}` + `data-component="{id}"`。
2. 只用已注册 slot key（`{{slot:key}}` / `{{#if}}` / `{{#each}}`）。
3. 不写微信不兼容特性（伪元素 / 结构伪类 / 绝对定位 / 动画 / 媒体查询 / 兄弟选择器）。
4. 模板里不写 CSS 值（style 属性一律不写）——那是 Stage 5 皮的职责。
5. 不为没有刻意构图理由的组件写骨架（保持默认，克制）。
