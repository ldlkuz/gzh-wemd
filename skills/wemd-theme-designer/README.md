# WeMD 主题生成器 · Skill 技能包

> **核心理念：Profile 驱动生成**
> Skill 不关心"你是企业还是个人"，它只关心有没有一份完整的 Profile。
> 生成逻辑只有一套，输入模板可扩展。

安装在 Trae / Codex / Trae Work 上的 AI 技能包。

---

## 架构一览

```
                    ┌─────────────────┐
                    │  用户第一句话     │
                    └────────┬────────┘
                             ▼
                    ┌─────────────────┐
                    │  判断 Profile 类型 │
                    └───┬──────────┬───┘
                        ▼          ▼
              ┌─────────────┐  ┌──────────────┐
              │ Brand Profile│  │Creator Profile│
              │ （品牌档案）  │  │（创作者档案） │
              │             │  │              │
              │ ✅ Logo      │  │ ✅ 公众号名称  │
              │ ✅ 企业简介   │  │ ✅ 内容方向    │
              │ ✅ 品牌关键词  │  │ ✅ 风格关键词  │
              │ ◯ 主色/官网   │  │ ◯ 主色/Logo   │
              │ ◯ Slogan/VI  │  │ ◯ 参考/Slogan │
              └──────┬──────┘  └──────┬───────┘
                     │                │
                     ▼                ▼
              ┌─────────────────────────────┐
              │     UnifiedProfile 统一结构    │
              │  (name, positioning,         │
              │   keywords, primaryColor,    │
              │   reference, slogan, ...)    │
              └──────────────┬──────────────┘
                             ▼
              ┌─────────────────────────────┐
              │     一套生成逻辑（完全复用）    │
              │  keywords → tone/density     │
              │  keywords → color/font       │
              │  keywords → variantCss       │
              │  → manifest.json             │
              │  → brand.md (仅 Brand)       │
              │  → .wemd-theme              │
              └─────────────────────────────┘
```

**关键设计：无论 Profile 来自哪个模板，进入生成逻辑后处理完全一致。**

## 两种 Profile 模板

### Brand Profile（品牌档案）— 适合企业

> 特征："我已经知道我要什么，你帮我实现。"

| 配置项     | 必填 | 说明                |
| ---------- | ---- | ------------------- |
| 企业名称   | ✅   |                     |
| 企业 Logo  | ✅   | PNG/SVG/JPG         |
| 企业简介   | ✅   | 100~300 字          |
| 品牌关键词 | ✅   | 3~5 个（18 词清单） |
| 品牌主色   | ◯    | #HEX 或从 Logo 提取 |
| 官网       | ◯    | 参考风格/配色       |
| Slogan     | ◯    |                     |
| VI 手册    | ◯    | PDF                 |

### Creator Profile（创作者档案）— 适合个人

> 特征："我知道我要表达什么，但不知道怎么设计。"

| 配置项     | 必填 | 说明                                                      |
| ---------- | ---- | --------------------------------------------------------- |
| 公众号名称 | ✅   |                                                           |
| 内容方向   | ✅   | 科技/AI/投资/情感/生活/摄影/美食/母婴/教育/职场/阅读/旅行 |
| 风格关键词 | ✅   | 3~5 个（同一套 18 词清单）                                |
| 主色       | ◯    | #HEX 或 AI 推荐                                           |
| Logo       | ◯    | 没有则 AI 做文字 Logo                                     |
| 参考风格   | ◯    | 喜欢的公众号/网站/一句话描述                              |
| Slogan     | ◯    |                                                           |

### 两种模板的差异

|          | Brand Profile        | Creator Profile           |
| -------- | -------------------- | ------------------------- |
| 名称     | 企业名称             | 公众号名称                |
| Logo     | **必填**             | 可选                      |
| 定位     | 企业简介 100~300字   | 内容方向（选类目+一句话） |
| 主色来源 | Logo 提取 / 用户提供 | AI 推荐 / 用户提供        |
| 参考     | 官网 / VI 手册       | 喜欢的公众号 / 网站       |
| brand.md | ✅ 写品牌语气        | ❌ 不写                   |
| 生成逻辑 | **完全一致**         | **完全一致**              |

## 18 个风格关键词（两种 Profile 共用）

```
专业  科技  年轻  高端  环保  可信
创新  温暖  极简  国际化  稳重  活力
理性  治愈  匠心  故事感  文艺  商务
```

不知道怎么选？告诉 AI 你的行业或内容方向，它会推荐组合：

| 行业/内容方向   | 推荐关键词                  |
| --------------- | --------------------------- |
| 科技/软件公司   | 专业 + 科技 + 创新 + 可信   |
| 金融/咨询/律所  | 专业 + 高端 + 稳重 + 可信   |
| 消费品/生活方式 | 温暖 + 年轻 + 活力 + 创新   |
| 科技/AI 创作者  | 专业 + 科技 + 极简 + 可信   |
| 情感/生活创作者 | 温暖 + 故事感 + 治愈 + 文艺 |
| 摄影/旅行创作者 | 极简 + 文艺 + 高端 + 故事感 |

完整推荐表见 [spec/brand-keywords.md](spec/brand-keywords.md)。

## 明确不支持（避免方向跑偏）

- ❌ PPT / Keynote / Word
- ❌ Figma / Sketch 设计稿
- ❌ 30 页以上企业文化 / 产品介绍
- ❌ 整个官网截图打包

这些可以作为**未来扩展**，但 V2.1 必须先把 Profile 模式做到位。

## 安装

### 在 Trae IDE 中安装

1. 打开 Trae IDE
2. 调用 `/skill-creator`（或命令面板搜索）
3. 选择「从本地文件夹安装」
4. 选择 `skills/wemd-theme-designer/` 目录
5. 安装完成后，AI 会在检测到触发词时自动激活

## 触发关键词

| 企业方向                    | 创作者方向                      |
| --------------------------- | ------------------------------- |
| 生成企业主题 / 企业品牌主题 | 生成创作者主题 / 个人公众号主题 |
| 品牌定制主题 / 企业VI 主题  | 自媒体主题 / 个人博客主题       |
| 公司公众号主题 / 品牌色主题 | 创作者主题 / 公众号风格主题     |
| 企业定制 WeMD 主题          | 生成公众号主题 / 内容创作者主题 |

**典型对话示例**：

企业用户：

```
我们公司「云帆科技」想做一个公众号主题。
Logo 我等下上传，企业简介是：
  我们是一家专注于工业自动化的软件企业，
  服务制造业客户，品牌定位是专业、可靠、高效。
关键词你推荐一下吧，我们是软件公司。
主色就用 #1a56db。
```

创作者用户：

```
我的公众号叫「AI效率实验室」，写 AI + 效率方向，
面向职场人。喜欢 Apple 官网那种感觉。
颜色你推荐吧，我想要专业、极简、高级的风格。
没有 Logo，你帮我做文字的就行。
```

## 使用流程（5 步）

```
┌─ Step 1 ─────────────────────────────┐
│ 对 AI 说一句「帮我做个主题」          │
│ AI 判断你是企业还是创作者，弹出对应   │
│ Profile 表单让你填                    │
└──────────────┬───────────────────────┘
               ▼
┌─ Step 2 ─────────────────────────────┐
│ Profile 齐全 → AI 先汇总确认          │
│ 问你是否确认，再开始真正生成          │
└──────────────┬───────────────────────┘
               ▼
┌─ Step 3 ─────────────────────────────┐
│ AI 输出三件套到 projects/ 目录：       │
│   projects/{项目名}/                   │
│   ├── manifest.json                   │
│   ├── brand.md  (仅 Brand Profile)   │
│   └── {项目名}.wemd-theme  (压缩包)    │
│ + 自检清单全部打勾                    │
└──────────────┬───────────────────────┘
               ▼
┌─ Step 4 ─────────────────────────────┐
│ 启动审核工作台预览所有组件效果         │
│   cd services && node cli.ts server  │
│   打开 http://127.0.0.1:3456          │
│ 审查 35 种组件渲染效果，标记不满意项   │
└──────────────┬───────────────────────┘
               ▼
┌─ Step 5 ─────────────────────────────┐
│ 根据反馈调整 → 重新生成 → 再次审查    │
│ 全部通过后交付最终 .wemd-theme 主题包  │
│ 直接拖入 WeMD 主程序导入使用          │
└──────────────────────────────────────┘
```

## 质量保障（内置检验）

检验已内置到 5 层设计管道中，无需独立检测工具：

```
┌─ 关卡 1：收集阶段 ───────────────────┐
│ Profile 必填项不全不允许开始生成     │
│ Brand: 缺 Logo/简介/关键词 都不行    │
│ Creator: 缺名称/内容方向/关键词 不行  │
└──────────────────────────────────────┘
               ▼
┌─ 关卡 2：AI 自检（prompts/self-check.md）│
│ A Profile 完整性（分模板检查）        │
│ B 关键词 → 设计决策对齐             │
│ C manifest 结构合规                 │
│ D brand.md 结构正确（仅 Brand）     │
│ E ZIP 输出结构正确                  │
└──────────────────────────────────────┘
```

## 未来扩展

新增类型只需：

1. 定义新的 Profile 模板（字段映射到 UnifiedProfile）
2. 如有特殊需求，在生成逻辑中加条件分支
3. 不需要改核心生成管线

可能的方向：

- **Edu Profile**（教育机构）— 加校徽、院系色、学术排版偏好
- **Media Profile**（媒体机构）— 加版权声明样式、多作者排版
- **Gov Profile**（政府机构）— 加公文格式约束、红色主色规范
